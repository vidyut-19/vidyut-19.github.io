Relling — Robot Deployment Systems

As a founding engineer at Relling, I'm standing up a bimanual UR5e work cell end to end: a Go control plane that owns robot drivers, camera health, and cell telemetry; the calibration and perception stack; a scripted manipulation baseline instrumented with a typed failure taxonomy and per-trial condition snapshots; and the data engine that takes teleop episodes through quality gates into VLA fine-tuning. Currently evaluating a fine-tuned open-weights VLA against the scripted baseline, with per-layer failure attribution. Active R&D — deployment in progress.

GELLO Teleop Rig + Data Engine

A GELLO-style teleoperation rig for the cell, plus the episode pipeline behind it: MCAP recording, automated quality gates, a review dashboard, and conversion to LeRobot format for policy training.

Distillery

Egocentric-video annotation at cloud scale — the distributed pipeline we ran before pivoting to robot deployments.

Javelin

Helped build the intelligence layer of athlete marketing at Javelin, an AI-native operating system for the athlete economy — semantic search on pgvector, a Go-based data pipeline with SQS, and an AI command center with structured-output SSE streaming. Built with NextJS, React Native, and AWS (Lambda, Amplify, Athena, Bedrock).
